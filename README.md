# Machine Learning Projects

This repository contains two independent projects exploring machine learning through practical implementation and interactive applications.

## Projects

### 1. Bank Marketing Classification

A supervised machine learning project that predicts whether a bank customer will subscribe to a term deposit based on marketing campaign information.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn.

**Highlights:**
- Data cleaning and exploratory data analysis.
- Comparison of multiple classification algorithms.
- Cross-validation and hyperparameter optimisation.
- Threshold selection and model evaluation.
- Feature importance and interpretation.

**Final model:** Tuned Random Forest.

**Test results:**
- Average Precision: 0.4624
- ROC-AUC: 0.7926
- F1-score: 0.4843
- Accuracy: 87.41%

See [Bank Marketing Classification](Bank-Marketing-Classification/README.md) for setup instructions and methodology.

### 2. ML Ninja

An interactive machine learning game combining a Fruit Ninja-inspired interface with classical machine learning algorithms.

**Technologies:** JavaScript, Three.js, Vite.

**Highlights:**
- Interactive 3D gameplay.
- Implementation of classical machine learning algorithms.
- Synthetic dataset visualisation.
- Interactive model training and decision boundaries.

See [ML Ninja](ML-Ninja/README.md) for installation and execution instructions.
